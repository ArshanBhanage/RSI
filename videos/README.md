# Walkthrough recordings

M00 is an additional preliminary walkthrough and does not count toward the 20 required lab/method videos. See `M00-video.json` for its hash and verification state. The source/execution capture is `M00-capture.json`.

Recreate on macOS with `uv run --python 3.13 videos/scripts/record_m00.py`. It executes the network source verifier, captures its actual output and renders actual source text with syntax highlighting. Reading pauses are added. The video has on-screen explanations and no audio or purported speech transcript. The local MP4 is under `videos/renders/`.
