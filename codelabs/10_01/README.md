# 10.01 — Distinguish Claim from Evidence

Distinguish an executed SQL speedup from an unsupported improvement claim. The checker binds a numerical claim to an actual evaluation ID, correct paired timings, data hash and evaluator identity. Its deliberately invalid 999x claim is a labeled rejection test, not a measurement. Target improvement alone does not establish RSI.
