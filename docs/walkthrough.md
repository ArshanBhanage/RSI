# Technical walkthrough

1. M00 pins all course, paper and released-code sources by commit and hash.
2. M01 records the runtime and credential availability without recording secrets.
3. M02 downloads official January/February 2025 NYC TLC Parquet and freezes eight query contracts.
4. M03 freezes SQL grammar, Docker image, evaluator code, budgets and paired timing rules.
5. Labs 10.01–10.17 build from claim validation through scoring, diagnosis, coordination, workflow evolution, security and metrics audit.
6. DREAM-RSI, AIDE²-inspired and RSIFlow adaptations each execute three search generations for seeds 17 and 29.
7. `queryforge compare --verify` reconstructs the matched 12-candidate search and one held-out transfer evaluation per run.
8. `scripts/build_site.py` derives the submission site from committed evidence; `scripts/check_delivery.sh` verifies publication structure and honest video status.
