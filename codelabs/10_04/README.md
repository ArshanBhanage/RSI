# 10.04 — Analyze the Scoring Mechanism

Fit a regularized linear readout to genuine historical SQL diff features and measured paired latency ratios. Four calibration rows train nine coefficients; the remaining four rows measure retrospective prediction error. This tiny, underdetermined fit does not establish generalization or prospective savings. The stored coefficients are frozen for the next lesson.
