# 10.02 — Audit an October 2026 Paper

Audit the original Budget RSI paper, including its held-out boundary, calibration cost and distinction from DREAM-RSI. A source correction matters: the paper does include Claude Sonnet 4.5 and Polyglot, contrary to the course claim/evidence summary. The executable validator checks audit fields and publisher title identity; it cannot automatically prove the scientific claims.

Prerequisites: complete M00–M03 and all preceding labs; `uv sync --locked`, authenticated Codex CLI, running Docker and checksum-verified TLC data. From the repository root:

```sh
uv run queryforge lab run 10.02
```

Implementation: [shared lesson code](../../src/queryforge/labs.py), [protected evaluator](../../src/queryforge/evaluator.py), [protocol](../../docs/evaluation-protocol.md). Input contracts are checked by the runnable lesson; failures stop execution rather than manufacture success. The output is [the actual JSON report](../../experiments/labs/10.02.json), which links the measurement or source evidence used. Read its interpretation together with the source-fidelity caveats. Missing source data, credentials or evidence is an error, not an offline simulation.
