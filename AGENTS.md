# QueryForge development rules

Only deliverable code, documentation, configs, tests, evidence and website source belong in this repository. Keep upstream source caches, raw datasets, authentication files and large renders out of Git.

Use actual TLC records or domain-free contract inputs in tests. Never substitute synthetic trip records or model replies. A failed experiment remains evidence. Do not change frozen evaluation rules in response to final-test results.

The owner deferred video production until after code verification and push on November 11, 2026. CODE_VERIFIED does not mean the final video/submission gate has passed. Proceed in milestone order; update evidence and commit each verified code milestone.
